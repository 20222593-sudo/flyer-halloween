# Flyer Halloween · Cornerstone

Flyer corporativo de Halloween (edición sostenible) para colaboradores de Cornerstone.

- `flyer-halloween-cornerstone.png` — versión para pantallas/redes (2400 × 3394 px)
- `flyer-halloween-cornerstone.pdf` — versión para impresión (proporción A4)
- `flyer.html` — archivo fuente editable (abre en el navegador; fuentes y logos en `assets/`)

Paleta: Cornerstone Dark Navy #0D1427, Blue #004887, Blue Accent #95C9E1 y #D8E8F5 (fondo) + acentos Halloween
(calabaza #EE7F35, luna #F2E8D0) y cartón reciclado #C9A77C.
Tipografías: Fraunces (título), Plus Jakarta Sans (texto), Caveat (detalle hecho a mano).

# Certificado Agente Cross · Cornerstone

Reconocimiento interno para colaboradores que destacan en la generación de leads y oportunidades comerciales.
Formato horizontal A4 (297 × 210 mm), listo para impresión.

- `certificado-agente-cross.pdf` — plantilla de impresión (vectorial, A4 horizontal) con el espacio `[NOMBRE DEL GANADOR]`
- `certificado-agente-cross.png` — vista previa en alta resolución (3509 × 2481 px, 300 dpi)
- `certificado-agente-cross.pptx` — versión editable en PowerPoint: doble clic en `[NOMBRE DEL GANADOR]`,
  escribir el nombre y exportar a PDF. Duplicar la diapositiva para cada colaborador.
- `certificado-agente-cross.html` — archivo fuente. Para personalizar: abrir en el navegador, escribir el nombre
  en el campo inferior (o usar `?nombre=Nombre%20Apellido` en la URL) y pulsar **Imprimir / PDF**
  (A4 horizontal, márgenes "Ninguno", con gráficos de fondo). Los nombres largos se ajustan solos.

Paleta: Dark Navy #0D1427, Blue #004887, Blue Accent #95C9E1 y #D8E8F5, con detalles dorados (#B8924A → #E8D49A).
Tipografías: Fraunces (título y nombre), Plus Jakarta Sans (texto). En el PowerPoint el nombre usa Georgia.
